Delivery Dash 🚚🍦

About

Delivery Dash is a 2D Unity game where the player drives an ice cream van and delivers ice cream to customers.
This project was built while learning Unity through a Udemy course, focusing on core game development concepts.

Features

- Player-controlled ice cream van movement
- Delivery system (pick up & deliver to customers)
- Simple 2D environment
- Basic collision and physics system

What I Learned

- Unity fundamentals (Scenes, GameObjects, Components)
- C# scripting in Unity
- Player movement and input handling
- Collision detection and triggers
- Basic game logic implementation

Tools Used

- Unity Engine
- C#

How to Run

1. Open the project in Unity Hub
2. Load the scene
3. Press Play
